[3] 경매 낙찰이 강력한 신호인 이유
================================================================

심리/행동 측면:
1. 승리자 효과 (Winner's High)
   - 경쟁에서 이긴 직후 도파민/테스토스테론 분비
   - 위험 감수 성향 일시 상승 → 추가 구매 저항선 낮아짐
2. 일관성 원칙 (Cialdini)
   - "나는 이걸 좋아하는 사람" 정체성을 입찰로 공개 선언
   - 보완재 제안 시 자기 설득 자동 작동
3. 소유 효과 (Endowment Effect)
   - 낙찰 = 이미 본인 것이라는 심리 → 보완재가 자연스럽게 연상

데이터 품질 측면:
- 일반 쇼핑몰: 클릭/카트/구매 (binary)
- 경매: 입찰 횟수·최종가·타이밍·경쟁자 수 → 연속값으로 강도 측정 가능
- 추천 알고리즘이 "얼마나 좋아하는지"까지 알 수 있음

시점/맥락 측면:
- 일반 쇼핑몰 "함께 구매" CTR: 평균 2~5%
- eBay 경매 낙찰 후 크로스셀 CTR: 15~25%
- 라이브커머스 실시간 추천 CTR: 10%+ (타오바오 라이브)
- 차이 3~5배 이상

발표 한 줄:
"경매 낙찰은 사용자가 시간·돈·감정을 모두 투자해
'나는 이게 정말 좋다'고 본인이 증명한 순간이다.
이만큼 깨끗한 구매 신호는 일반 쇼핑몰에선 만들 수 없다."

[8] 추천 알고리즘 상세 — RuleBasedRecommender 4단계 하이브리드
================================================================

입력 (AuctionWin):
- auctionId, itemName, category, finalPrice, description?

출력 (Recommendation):
- product, score (0~1), reasons[] (시연용 핵심)

가중치 합 = 1.0:
① 카테고리 매핑 룰 (0.35)
   - itemName 키워드 추출
   - mall 상품의 complementaryHints 배열 매칭
   - 정확 매칭 1.0 / 부분 0.6 / 동일 카테고리 0.3 / 그 외 0

② 가격대 매칭 (0.25)
   - 낙찰가 분위수: low < 10000 / mid 10000~50000 / high >= 50000
   - 일치 1.0 / 인접 티어 0.5 / 정반대 0

③ 콘텐츠 유사도 (0.25)
   - 키워드 Jaccard 유사도
   - 임베딩 모델 사용 금지 (의존성 추가 X)

④ 다양성 보너스 (0.15)
   - 같은 카테고리가 N/2 초과 시 후순위 -0.1

데모 시나리오 결과:
- "갈치 1박스" (수산, 35,000원) → 1위: 제주 갈치 1마리 (0.792)
- "한우 등심 500g" (축산, 80,000원) → 1위: 한우 등심 300g (0.797)
- "충주 사과 5kg" (과일, 25,000원) → 1위: 충주 햇사과 5kg (0.875)
